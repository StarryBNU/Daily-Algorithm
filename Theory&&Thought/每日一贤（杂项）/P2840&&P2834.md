洛谷题目 **P2840 纸币问题 2** 与 **P2834 纸币问题 3** 虽然都属于“纸币类”动态规划问题，且都涉及**完全背包模型**，但它们在**问题目标、计数方式、状态转移顺序**等方面有本质区别。下面从多个维度详细对比：

---

### 一、题目目标不同

| 题号      | 题目名称   | 问题类型                 | 目标                                                 |
| --------- | ---------- | ------------------------ | ---------------------------------------------------- |
| **P2840** | 纸币问题 2 | **方案数（考虑顺序）**   | 求支付金额 `w` 的**不同支付序列数**（即 **排列数**） |
| **P2834** | 纸币问题 3 | **方案数（不考虑顺序）** | 求支付金额 `w` 的**不同纸币组合数**（即 **组合数**） |

> ✅ 关键区别：  
> - **P2840 中 1+2 和 2+1 算两种方案**（顺序不同即不同）  
> - **P2834 中 1+2 和 2+1 算同一种方案**（只看用了哪些面额，不管顺序）

---

### 二、DP 循环顺序不同（核心实现差异）

这是两类问题在代码上的根本区别：

#### ✅ P2840（排列数）——外层枚举金额，内层枚举纸币
```cpp
for (int i = 1; i <= w; i++)          // 外层：金额
    for (int j = 0; j < n; j++)       // 内层：每种纸币
        if (a[j] <= i)
            dp[i] = (dp[i] + dp[i - a[j]]) % MOD;
```
- 这样会**重复计入不同顺序**，例如先选1再选2，和先选2再选1都会被分别计算。
- 属于 **“完全背包求排列数”** 的标准写法。

#### ✅ P2834（组合数）——外层枚举纸币，内层枚举金额
```cpp
for (int j = 0; j < n; j++)           // 外层：每种纸币
    for (int i = a[j]; i <= w; i++)   // 内层：金额（从小到大）
        dp[i] = (dp[i] + dp[i - a[j]]) % MOD;
```
- 每种纸币**一次性处理完所有能更新的状态**，保证不会出现“先用后面纸币再用前面”的情况。
- 这样每种组合**只按纸币种类顺序生成一次**，避免重复。
- 属于 **“完全背包求组合数”** 的标准写法。

> 🔥 总结：  
> - **先物品后容量 → 组合数（P2834）**  
> - **先容量后物品 → 排列数（P2840）**

---

### 三、举例说明

假设纸币面额为 `[1, 2]`，目标金额 `w = 3`：

| 方案  | P2840（排列）是否计入 | P2834（组合）是否计入 |
| ----- | --------------------- | --------------------- |
| 1+1+1 | ✅ 是                  | ✅ 是                  |
| 1+2   | ✅ 是                  | ✅ 是                  |
| 2+1   | ✅ 是                  | ❌ 否（与1+2视为相同） |
|       | **总计：3 种**        | **总计：2 种**        |

实际输出：
- P2840 输出 `3`
- P2834 输出 `2`

---

### 四、模数要求（次要区别）

- **P2840**：通常要求对 `10^9+7` 取模（根据题面）
- **P2834**：可能要求对 `10000` 或其他数取模（需看具体题目描述）

但这个不是本质区别，只是输入输出细节。

---

### 五、总结对比表

| 维度         | P2840 纸币问题 2          | P2834 纸币问题 3                       |
| ------------ | ------------------------- | -------------------------------------- |
| 问题类型     | 完全背包（排列数）        | 完全背包（组合数）                     |
| 是否区分顺序 | 是                        | 否                                     |
| DP 循环顺序  | 金额在外，纸币在内        | 纸币在外，金额在内                     |
| 典型应用场景 | 支付序列、路径计数        | 货币组合、集合划分                     |
| 状态转移思想 | “到达金额 i 有多少种走法” | “用前 j 种纸币组成金额 i 有多少种方法” |

### 附：符合 C++98 标准的参考代码（无 vector / auto 等）

#### P2840（排列数）
```cpp
#include <iostream>
using namespace std;
const int MOD = 1000000007;
const int MAXW = 10005;
long long dp[MAXW];
int a[1005];

int main() {
    int n, w;
    cin >> n >> w;
    for (int i = 0; i < n; i++) cin >> a[i];
    dp[0] = 1;
    for (int i = 1; i <= w; i++)
        for (int j = 0; j < n; j++)
            if (a[j] <= i)
                dp[i] = (dp[i] + dp[i - a[j]]) % MOD;
    cout << dp[w] % MOD;
    return 0;
}
```

#### P2834（组合数）
```cpp
#include <iostream>
using namespace std;
const int MOD = 10000; // 注意：P2834 模 10000
const int MAXW = 10005;
long long dp[MAXW];
int a[1005];

int main() {
    int n, w;
    cin >> n >> w;
    for (int i = 0; i < n; i++) cin >> a[i];
    dp[0] = 1;
    for (int j = 0; j < n; j++)
        for (int i = a[j]; i <= w; i++)
            dp[i] = (dp[i] + dp[i - a[j]]) % MOD;
    cout << dp[w] % MOD;
    return 0;
}
```

> ⚠️ 注意：P2834 的模数是 **10000**，不是 `1e9+7`，务必看清题目！

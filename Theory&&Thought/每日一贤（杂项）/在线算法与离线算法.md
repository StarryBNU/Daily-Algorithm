在算法竞赛（尤其是 OI / ACM 类比赛）中，**离线算法**（offline algorithm）是指**在处理问题之前，已经知道全部输入数据**，并可以**预先对所有查询或操作进行整体处理**的一类算法。

与之相对的是**在线算法**（online algorithm），它必须在**每次接收到一个查询或操作后立即给出答案**，不能预知未来的输入。

---

### 举个例子说明区别：

#### 问题：区间求和
给定一个数组 `a[1..n]`，有 `q` 次查询，每次问 `[l, r]` 区间内元素的和。

- **在线做法**：每次读入一个查询 `(l, r)`，立刻输出答案。比如用前缀和 `O(1)` 回答，这是可行的。
- **离线做法**：先把所有 `q` 个查询都读进来，然后按某种顺序（比如按右端点排序）统一处理，再输出答案。例如用 **莫队算法** 或 **树状数组 + 离线排序**。

---

### 常见的离线算法/技巧包括：

1. **莫队算法（Mo's Algorithm）**  
   - 用于处理可离线的区间查询（如区间不同数个数、区间众数等）。
   - 核心思想：将查询分块 + 排序，利用相邻查询的相似性减少重复计算。

2. **离线处理 + 树状数组 / 线段树**  
   - 例如：求“有多少对 (i, j) 满足 i < j 且 a[i] > a[j]”（逆序对），可以离线处理。
   - 又如：带修改的区间查询，若修改和查询都已知，可离线用 **CDQ 分治**。

3. **CDQ 分治**  
   - 一种处理“带修改和查询”的离线分治方法，常用于三维偏序等问题。

4. **整体二分（Parallel Binary Search）**  
   - 对多个查询同时进行二分，利用离线性质批量处理。

---

### 离线算法的优点：

- 可以**重新安排处理顺序**，优化时间复杂度。
- 能利用**全局信息**设计更高效的策略。
- 在某些问题上（如莫队），是唯一可行的高效解法。

### 缺点：

- **不能用于强制在线的问题**（比如题目要求每次输入后立刻输出，且后续输入依赖当前输出）。
- 需要额外空间存储所有查询。

### C++98 竞赛中的典型离线写法（示例：莫队）

```cpp
#include <cstdio>
#include <algorithm>
#include <cmath>
using namespace std;

const int MAXN = 50005;
const int MAXQ = 200005;

struct Query {
    int l, r, id;
} q[MAXQ];

int n, m, a[MAXN], ans[MAXQ], cnt[MAXN * 2], block;
long long now;

bool cmp(const Query &a, const Query &b) {
    if (a.l / block != b.l / block)
        return a.l < b.l;
    return a.r < b.r;
}

void add(int x) {
    now += cnt[a[x]]++;
}
void del(int x) {
    now -= --cnt[a[x]];
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; ++i) scanf("%d", &a[i]);
    scanf("%d", &m);
    block = sqrt(n);
    for (int i = 0; i < m; ++i) {
        scanf("%d%d", &q[i].l, &q[i].r);
        q[i].id = i;
    }
    sort(q, q + m, cmp);
    
    int l = 1, r = 0;
    for (int i = 0; i < m; ++i) {
        while (l > q[i].l) add(--l);
        while (r < q[i].r) add(++r);
        while (l < q[i].l) del(l++);
        while (r > q[i].r) del(r--);
        ans[q[i].id] = now;
    }
    for (int i = 0; i < m; ++i) printf("%d\n", ans[i]);
    return 0;
}
```

> 注意：以上代码符合 C++98 标准（无 auto、vector 等 C++11 特性）。

---

### 总结

- **离线 = 所有输入已知 + 可重新排序处理**
- **在线 = 边读边答，不能回头**
- 离线是算法竞赛中非常重要的思想，尤其在处理复杂查询时能大幅优化效率。

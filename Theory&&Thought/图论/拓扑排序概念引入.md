**拓扑排序** 是对 **有向无环图** 的所有顶点的一种线性排序。这个排序满足一个条件：如果图中存在一条从顶点 U 指向顶点 V 的边，那么在排序结果中，U 必须出现在 V 之前。

简单来说，拓扑排序能让你找到一种“顺序”，使得所有依赖关系都被满足。就像你要穿袜子再穿鞋，不可能反过来一样。

### 1. 为什么需要拓扑排序？
*   **依赖解析**：比如大学课程有先修要求（学完《高等数学》才能学《线性代数》），拓扑排序可以给出一个合理的选课顺序。
*   **任务调度**：项目任务之间有前后依赖，拓扑排序能找出一个可执行的顺序。
*   **在 P3387 中的应用**：将原图缩点得到有向无环图后，我们需要计算最大权路径。这时可以用拓扑排序的顺序进行动态规划，因为按照拓扑序处理节点，可以保证计算某个节点时，它所有前驱节点的最优值都已经计算完毕。

### 2. 拓扑排序的算法（Kahn 算法）
Kahn 算法是基于贪心思想，使用队列来实现的，步骤如下：
1.  **计算入度**：统计每个节点的入度（有多少条边指向它）。
2.  **初始化队列**：将所有入度为 0 的节点加入队列（这些节点没有前置依赖，可以先处理）。
3.  **循环处理**：
    *   从队列中取出一个节点，将其加入排序结果中。
    *   “删除”该节点发出的所有边：对于它的每个邻接节点，将邻接节点的入度减 1。
    *   如果某个邻接节点的入度变为 0，则将其加入队列。
4.  **结束**：重复步骤 3 直到队列为空。
    *   如果最终排序结果中的节点数等于总节点数，说明图是**有向无环图**，拓扑排序成功。
    *   如果节点数少于总节点数，说明图中存在环，无法进行拓扑排序。

### 3. 一个简单的例子
假设你要穿衣服，顺序依赖关系如下：
*   必须先穿内衣，才能穿外套。
*   必须先穿袜子，才能穿鞋。
*   必须先穿裤子，才能穿鞋。

用有向图表示：
内衣 → 外套  
袜子 → 鞋  
裤子 → 鞋  

入度：内衣(0)、袜子(0)、裤子(0)、外套(1)、鞋(2)  

拓扑排序过程：
1. 入度为 0 的节点有内衣、袜子、裤子，都可以先处理。假设先取出内衣 → 排序结果：[内衣]；删除内衣→外套的边，外套入度变 1 还是 0？原本外套入度 1，减 1 后变 0，所以外套加入队列。
2. 队列现在有袜子、裤子、外套。取出袜子 → 排序结果：[内衣, 袜子]；删除袜子→鞋的边，鞋入度 2→1。
3. 取出裤子 → 排序结果：[内衣, 袜子, 裤子]；删除裤子→鞋的边，鞋入度 1→0，鞋加入队列。
4. 取出外套 → 排序结果：[内衣, 袜子, 裤子, 外套]；外套没有出边。
5. 取出鞋 → 排序结果：[内衣, 袜子, 裤子, 外套, 鞋]。

最终得到的一个拓扑排序是：**内衣 → 袜子 → 裤子 → 外套 → 鞋**。你会发现它满足了所有依赖（比如穿内衣在外套之前，穿袜子、裤子都在鞋之前）。

### 4. 拓扑排序的特点
*   **不唯一**：如果同一时刻有多个入度为 0 的节点，可以任意选择顺序，因此拓扑排序可能有多种结果。
*   **只适用于有向无环图**：如果图中有环，环上的节点入度永远不会变为 0，所以算法无法处理完所有节点。

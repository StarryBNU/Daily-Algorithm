在算法竞赛（尤其是 C++98 环境下）中，动态规划（DP）是一类极其重要且高频的解题范式。DP 的“常用对象”通常指**经典题型或模型**，这些题型具有清晰的状态定义、转移方程和边界条件，掌握它们能快速识别并解决大量问题。

以下是 DP 最常见的经典题型（按类别划分），每类附简要说明和典型代表：

---

### 一、线性 DP（序列型）

**特点**：状态按一维序列展开，常用于处理数组、字符串等线性结构。

| 题型                      | 说明                                             | 典型题目 |
| ------------------------- | ------------------------------------------------ | -------- |
| **最大子段和**            | `dp[i] = max(a[i], dp[i-1] + a[i])`              | HDU 1003 |
| **最长上升子序列（LIS）** | `dp[i] = max(dp[j] + 1)`（j < i 且 a[j] < a[i]） | POJ 2533 |
| **最长公共子序列（LCS）** | `dp[i][j] = dp[i-1][j-1]+1`（若 s[i]==t[j]）     | POJ 1458 |
| **编辑距离**              | 插入、删除、替换操作的最小代价                   | POJ 3356 |

> ✅ **关键**：状态表示以“前 i 个元素”结尾的最优值。

---

### 二、背包 DP

**特点**：有限资源（容量/重量）下选择物品使价值最大，是最经典的 DP 模型。

| 类型         | 状态定义                                   | 转移方程                                             | 注意                         |
| ------------ | ------------------------------------------ | ---------------------------------------------------- | ---------------------------- |
| **01 背包**  | `dp[i][j]`：前 i 个物品，容量 j 的最大价值 | `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])` | 二维可压一维，**倒序枚举 j** |
| **完全背包** | 物品无限用                                 | `dp[j] = max(dp[j], dp[j - w[i]] + v[i])`            | **正序枚举 j**               |
| **多重背包** | 每种物品有数量限制                         | 可二进制拆分转 01 背包                               | 或单调队列优化（NOIP 常考）  |
| **分组背包** | 每组选至多一个                             | 外层组，内层容量倒序                                 | 类似 01 背包嵌套             |

> ✅ **C++98 实现提示**：用 `int dp[MAXN]; memset(dp, 0, sizeof dp);`

---

### 三、区间 DP

**特点**：状态表示为区间 `[l, r]`，常用于合并、删除、回文等问题。

| 题型               | 状态定义                           | 转移方式                                                     |
| ------------------ | ---------------------------------- | ------------------------------------------------------------ |
| **石子合并**       | `dp[l][r]`：合并 l~r 的最小代价    | 枚举分割点 k：`dp[l][r] = min(dp[l][k] + dp[k+1][r] + sum[l][r])` |
| **最长回文子序列** | `dp[l][r]`：s[l..r] 中最长回文长度 | 若 s[l]==s[r]，则 `dp[l][r] = dp[l+1][r-1] + 2`              |
| **矩阵链乘**       | 最少标量乘法次数                   | 枚举断点 k                                                   |

> ✅ **实现顺序**：按区间长度 `len = 1 to n` 递增枚举。

```cpp
for (int len = 2; len <= n; ++len)
    for (int l = 1; l + len - 1 <= n; ++l) {
        int r = l + len - 1;
        dp[l][r] = INF;
        for (int k = l; k < r; ++k)
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost);
    }
```

---

### 四、树形 DP

**特点**：在树上进行 DP，通常以子树为状态，通过 DFS 后序遍历计算。

| 题型                    | 说明                                     |
| ----------------------- | ---------------------------------------- |
| **没有上司的舞会**      | 经典：选节点不能选父节点，求最大权独立集 |
| **树的直径（DP 解法）** | 记录每个点向下最长、次长路径             |
| **树上背包**            | 如“选课”问题（依赖背包）                 |

> ✅ **状态设计**：`dp[u][0/1]` 表示 u 节点不选/选时的最大值。

```cpp
void dfs(int u) {
    dp[u][1] = val[u];
    for (each son v of u) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}
```

---

### 五、状压 DP（状态压缩）

**特点**：用整数二进制位表示状态（如选了哪些元素），适用于 n ≤ 20 的小规模问题。

| 题型                   | 说明                                                |
| ---------------------- | --------------------------------------------------- |
| **旅行商问题（TSP）**  | `dp[mask][i]`：已访问集合 mask，当前在 i 的最短路径 |
| **铺瓷砖 / 骨牌覆盖**  | 用位表示当前行状态，逐行转移                        |
| **作业调度（带依赖）** | 状态为已完成作业集合                                |

> ✅ **技巧**：用 `(mask >> i) & 1` 判断第 i 位是否为 1。

---

### 六、数位 DP

**特点**：统计 [0, N] 中满足某性质的数字个数（如不含连续 4 和 9）。

| 要素     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| **状态** | `dp[pos][tight][pre][...]`（pos: 当前位，tight: 是否受限，pre: 前一位数字） |
| **方法** | 从高位到低位 DFS + 记忆化                                    |

> ✅ **模板性强**，常用于“计数类”问题。

---

### 七、概率/期望 DP

**特点**：状态表示期望或概率，转移带权重（如 `E = Σ p_i * (cost_i + E_next)`）。

| 题型               | 说明            |
| ------------------ | --------------- |
| **掷骰子期望步数** | 从终点倒推      |
| **收集邮票问题**   | 期望线性性 + DP |

> ✅ **注意**：通常**逆序 DP**（从结果往起点推）。

---

### 总结：DP 题型速查表

| 类别    | 关键词       | 状态维度              | 典型场景         |
| ------- | ------------ | --------------------- | ---------------- |
| 线性 DP | 序列、子序列 | 1D / 2D               | LIS, LCS         |
| 背包    | 容量、价值   | 1D（滚动）            | 01/完全/多重背包 |
| 区间 DP | 合并、回文   | 2D（l, r）            | 石子合并         |
| 树形 DP | 子树、父子   | 2D（u, 0/1）          | 选课、独立集     |
| 状压 DP | 二进制、集合 | 2D（mask, i）         | TSP、铺砖        |
| 数位 DP | 数字、计数   | 多维（pos, tight...） | 不含某数字的数   |
| 期望 DP | 概率、期望   | 1D                    | 随机游走         |

---

掌握以上模型后，遇到新题可尝试**匹配模型**或**组合模型**（如“树上背包”=树形+背包，“带限制的LIS”=线性+状压）。在 C++98 环境下，注意数组大小、`memset` 初始化、避免 STL 过度使用（如优先用 `int dp[1005][1005]` 而非 `vector`）。

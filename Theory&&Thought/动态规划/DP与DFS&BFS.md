动态规划（Dynamic Programming, DP）和搜索（如 BFS、DFS）都是解决**最优化问题**或**状态空间遍历问题**的重要算法思想，它们在某些场景下有交集，但核心思想、适用条件和实现方式存在明显区别。下面从多个角度分析它们的关系与差异：

---

### 一、共同点

1. **都用于状态空间探索**  
   - DP 和搜索（BFS/DFS）本质上都在处理“状态”之间的转移。
   - 比如：走迷宫（每个格子是一个状态）、背包问题（物品选择构成状态）等。

2. **都可以用递归/记忆化形式表达**  
   - DFS 可以写成递归；DP 也可以用记忆化搜索（即带 memo 的递归 DFS）实现。
   - 例如：斐波那契数列既可用朴素递归（DFS），也可用记忆化递归（DP）。

3. **都能解决最短路径/最优解问题**  
   - BFS 在无权图中求最短路径；
   - DP 在有向无环图（DAG）或满足最优子结构的问题中求最优解。

---

### 二、核心区别

| 维度              | 动态规划（DP）                                            | 搜索（BFS / DFS）                  |
| ----------------- | --------------------------------------------------------- | ---------------------------------- |
| **核心思想**      | 利用**最优子结构** + **重叠子问题**，通过填表避免重复计算 | 系统性地遍历所有可能的状态（穷举） |
| **是否剪枝/优化** | 必须利用子问题的最优性，避免无效状态                      | 可加入剪枝（如回溯），但本质是枚举 |
| **时间复杂度**    | 通常为多项式（状态数 × 转移数）                           | 可能指数级（如全排列）             |
| **适用条件**      | 问题需满足：**最优子结构** + **无后效性**                 | 无需满足 DP 条件，通用性强         |
| **实现方式**      | 递推（自底向上）或记忆化搜索（自顶向下）                  | 递归（DFS）或队列（BFS）           |

---

### 三、DP 与搜索的转化关系

#### 1. **记忆化搜索 = DFS + DP**
- 当一个问题具有重叠子问题时，普通 DFS 会重复计算。
- 加上 `memo` 数组缓存已计算结果，就变成了 **记忆化搜索**，这本质上是 DP 的一种实现方式。
- 例：求最长递增子序列（LIS）可用 DFS 枚举，但用记忆化后就是 DP。

```cpp
// 记忆化搜索示例（LIS 的一种写法）
int dp[1005]; // 初始化为 -1
int dfs(int i, vector<int>& a) {
    if (dp[i] != -1) return dp[i];
    dp[i] = 1;
    for (int j = i + 1; j < a.size(); ++j)
        if (a[j] > a[i])
            dp[i] = max(dp[i], dfs(j, a) + 1);
    return dp[i];
}
```

#### 2. **BFS 与 DP 的联系**
- 在**无权图最短路径**问题中，BFS 天然保证第一次到达某点即是最短路径。
- 若将每个状态看作图中的节点，BFS 实际上是在按“层数”（步数）进行 DP。
- 例如：01BFS、多源 BFS 有时可视为 DP 的特例。

> 特别地，在**DAG 上的最短路径**问题中，拓扑排序 + DP 与 BFS 思想相通。

---

### 四、何时用 DP？何时用搜索？

| 场景                                    | 推荐方法             |
| --------------------------------------- | -------------------- |
| 状态数少、但分支多（如 n ≤ 20）         | DFS + 剪枝（回溯）   |
| 有重叠子问题、最优子结构（如背包、LIS） | DP（递推或记忆化）   |
| 求无权图最短路径                        | BFS                  |
| 状态空间大但可压缩（如位掩码）          | 状压 DP（本质是 DP） |
| 需要输出所有解（而非最优解）            | DFS                  |

---

### 五、总结一句话

> **DP 是“聪明的搜索”** —— 它通过识别问题的结构（最优子结构、无后效性），避免了搜索中大量重复或无效的路径，从而将指数时间优化为多项式时间。

而 BFS/DFS 是更通用的暴力框架，DP 是在其基础上加入“数学结构洞察”后的高效特化。

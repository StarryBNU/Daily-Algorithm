在 C++（特别是算法竞赛中常用的 C++98 标准）中，**iterator（迭代器）** 是一种用于访问容器（如 `vector`、`list`、`set`、`map` 等）中元素的对象。你可以把它想象成一个“泛化的指针”——它指向容器中的某个位置，并支持类似指针的操作（比如解引用 `*it`、自增 `++it` 等），但具体行为取决于容器类型。

---

### 1. **基本作用**
迭代器提供了一种统一的方式来遍历不同类型的容器，而不需要关心底层数据结构是数组、链表还是红黑树。

---

### 2. **常见操作（C++98 中）**

假设 `it` 是一个迭代器：

- `*it`：获取当前指向的元素（解引用）
- `++it` 或 `it++`：移动到下一个元素
- `==` / `!=`：比较两个迭代器是否指向同一位置（常用于循环终止条件）
- （注意：不是所有迭代器都支持 `--it` 或 `it + n`，这取决于迭代器类别）

---

### 3. **使用示例（C++98 风格）**

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v;
    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    // 声明迭代器（C++98 必须写全类型）
    std::vector<int>::iterator it;
    for (it = v.begin(); it != v.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

输出：
```
10 20 30
```

---

### 4. **不同类型容器的迭代器**

| 容器      | 迭代器类型     | 支持的操作                       |
| --------- | -------------- | -------------------------------- |
| `vector`  | 随机访问迭代器 | `++`, `--`, `+n`, `-n`, `[]` 等  |
| `deque`   | 随机访问迭代器 | 同上                             |
| `list`    | 双向迭代器     | `++`, `--`，但不支持 `+n`        |
| `set/map` | 双向迭代器     | 按序遍历（中序），不支持随机跳转 |

---

### 5. **const_iterator**

如果容器是 `const` 的，或者你不想修改元素，应使用 `const_iterator`：

```cpp
std::vector<int>::const_iterator cit;
for (cit = v.begin(); cit != v.end(); ++cit) {
    std::cout << *cit << " "; // 只读
}
```

---

### 6. **注意事项（算法竞赛中）**

- 在 C++98 中，**不能用 `auto`**，必须显式写出迭代器类型。
- 修改容器时（如 `erase`、`insert`），某些迭代器会**失效**。例如：
  ```cpp
  it = v.erase(it); // erase 返回下一个有效迭代器
  ```
- `map` 的迭代器解引用后得到的是 `pair<const Key, Value>`，访问方式为 `it->first` 和 `it->second`。

---

### 总结

> **Iterator 是 STL 容器和算法之间的桥梁**。它让 `sort(v.begin(), v.end())`、`find(v.begin(), v.end(), x)` 等通用算法成为可能，而无需为每种容器单独实现。

在算法竞赛中，熟练使用迭代器能让你高效操作 STL 容器，写出简洁可靠的代码。

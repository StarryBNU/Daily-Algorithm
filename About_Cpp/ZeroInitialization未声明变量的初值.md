在 C++ 中，**全局变量**（包括命名空间作用域的变量、静态全局变量）如果没有显式初始化，其**初始值是 0**（或等效的零值），这是由 C++ 标准规定的 **“零初始化”（zero-initialization）** 规则所保证的。

### 具体说明：

- **全局变量**（具有静态存储期）在程序启动前会经历两个阶段的初始化：
  1. **零初始化（Zero-initialization）**：所有未显式初始化的静态存储期变量（包括全局变量和 `static` 变量）都会先被初始化为 0（对基本类型而言）或等效的零值（如指针为 `nullptr`，类对象成员为零等）。
  2. **动态初始化（Dynamic initialization）**：如果提供了初始化器（比如 `int x = 42;`），则在此阶段执行。

因此，即使你写：

```cpp
int global_var;        // 未初始化
double global_array[10];
char* global_ptr;
bool global_flag;
```

这些变量在程序开始运行 `main()` 之前，都会被自动初始化为：

- `global_var == 0`
- `global_array` 中每个元素都是 `0.0`
- `global_ptr == nullptr`
- `global_flag == false`

> ✅ 这适用于所有具有**静态存储期**的变量，包括：
> - 全局作用域变量
> - 命名空间作用域变量
> - 函数内的 `static` 变量
> - 类中的 `static` 成员变量（如果定义在全局作用域）

---

### 对比：局部变量（自动存储期）

注意：**局部变量**（在函数内部定义、非 `static`）**不会被自动初始化**，其值是未定义的（通常是垃圾值）：

```cpp
void func() {
    int local;  // 未初始化！值是未定义的
    cout << local; // 危险！可能输出任意值
}
```

---

### 总结

| 变量类型               | 是否自动初始化为 0？ |
| ---------------------- | -------------------- |
| 全局变量               | ✅ 是                 |
| `static` 全局/局部变量 | ✅ 是                 |
| 普通局部变量           | ❌ 否（未定义值）     |

所以，**C++ 的全局变量在声明时未指定值，初始值确实是 0（或零值）**。

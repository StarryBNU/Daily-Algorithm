`unsigned` 是 **C语言**（以及 C++ 等其他编程语言）中的一个**类型修饰关键字**，用于声明**无符号整数类型**。

---

### 一、基本含义

- `unsigned` 表示该变量 **只能存储非负整数**（即：0 和正整数），**不能表示负数**。
- 它通常与整型（如 `int`、`char`、`short`、`long` 等）一起使用。

例如：

```c
unsigned int a;      // 无符号整型
unsigned char c;     // 无符号字符型
unsigned long l;     // 无符号长整型
```

也可以简写为：

```c
unsigned a;          // 等价于 unsigned int a;
```

---

### 二、与 `signed` 的区别

| 类型                     | 能否表示负数 | 典型取值范围（32位系统）        |
| ------------------------ | ------------ | ------------------------------- |
| `int`（即 `signed int`） | ✅ 可以       | -2,147,483,648 到 2,147,483,647 |
| `unsigned int`           | ❌ 不可以     | 0 到 4,294,967,295              |

> 💡 因为 `unsigned` 不需要保留一位作为符号位，所以它的**最大正值比有符号类型大将近一倍**。

---

### 三、输入输出格式说明符

- 有符号整数：用 `%d`
- 无符号整数：用 `%u`

示例：

```c
#include <stdio.h>
int main() {
    unsigned int a = 4000000000U;
    printf("%u\n", a);  // 正确输出无符号数
    return 0;
}
```

---

### 四、常见用途

1. **表示天然非负的数据**：如年龄、人数、数组下标、文件大小等。
2. **提高数值上限**：当确定数据不会为负，又希望利用更大的正数范围时。
3. **位运算和底层开发**：在嵌入式、驱动、网络协议等场景中常用于精确控制二进制位。

---

### 五、注意事项 ⚠️

- 如果给 `unsigned` 变量赋一个负值（如 `unsigned int x = -1;`），**不会报错**，但会**发生模运算**，结果是一个很大的正数（例如在32位系统中，`-1` 会变成 `4294967295`）。
- 混合使用 `signed` 和 `unsigned` 进行比较或运算时，**容易引发隐式类型转换错误**，需特别小心。

---

### 总结一句话：

> **`unsigned` 是 C 语言中用于声明“只能存非负整数”的关键字，能扩大正数表示范围，但不能表示负数。**

如果你是初学者，记住：**“unsigned = 无负号 = 只能是 0 或正数”** 就够了！
